# R5Flowstate 360° 发射寻敌

## 行为与操作

独立离线安装 `D:\R5Flowstate\Game` 的中文菜单中，“弹道修正”是总开关，“360° 全方位搜索”控制全向模式。全向模式优先最近的可见 NPC／其他玩家，排除自己和诱饵类别；没有合格目标时沿用普通射击。

每次开火重新选择目标，在弹丸生成调用前校准初始方向，由原生流程计算速度与散布。出膛后不添加追踪转向，继续执行原有重力、阻力和碰撞。移动目标、武器散布和远距离下坠仍可能影响命中，不保证每发必中。

关闭全向模式可回到原先的小角度范围。内部参数 `local_bullet_angle=180` 表示 180° 半角，即完整 360°；菜单显示的“360°”不是把内部半角直接改成 360。

## 附录：故障与修复证据

初期只扩大角度范围，方向函数能返回身后方向，但实际开火未命中。原生入口日志显示方向在上层流程中已被改回前方，因而增加了创建时校准及原生可见目标检查。

一个候选在新增的弹丸速度读取调用中崩溃，匹配转储定位到 `BoltVel_GetAbsVelocity` 内的错误返回值解引用。该额外读写已移除，最终实现保留原生速度计算。崩溃 DLL/PDB、转储定位输出和失败实弹报告均留在证据目录；最终版本随后通过三组实弹对照。这不构成长时间稳定性保证，也不表示历史主菜单退出原因已经解决。
