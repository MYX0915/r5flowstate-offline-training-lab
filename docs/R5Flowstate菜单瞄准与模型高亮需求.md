# R5Flowstate 菜单、瞄准辅助与模型高亮

## 范围

独立安装的 R5Flowstate 本机离线训练场，目录 `D:\R5Flowstate\Game`。目标类别为 NPC 和其他玩家实体；排除本地自己、诱饵和普通物件。

## GUI 与瞄准辅助

- Insert 显示或隐藏游戏内 GUI。
- 菜单使用中文，并加载本机中文字体。
- 菜单可启用或关闭辅助瞄准，选择头、脖子、胸、手、腿。
- 部位使用真实模型骨骼数据；缺少有效骨骼时跳过目标，不用包围框比例假装部位。
- 按住鼠标右键时才允许调整视角，松开立即停止。
- 菜单打开或游戏失去焦点时暂停视角调整。
- 屏幕中心显示范围圆，菜单可调整半径。
- 只选择指定部位投影点位于圆内的有效 NPC／其他玩家，排除自己和诱饵。
- 不自动开火。

## 模型高亮

现行要求替换此前的人物方框：

| 模型状态 | 外围轮廓 | 模型内部 |
| --- | --- | --- |
| 无遮挡 | 绿色高亮 | 不填充 |
| 部分遮挡 | 绿色高亮 | 只有被遮挡的部分填充红色 |
| 完全遮挡 | 绿色高亮 | 全身填充红色 |

遮挡按模型片段的深度关系处理。头、胸等单个点的射线判断不能代替部分遮挡效果。实现应优先核对引擎已有高亮／模型材质能力；只有运行画面证明部分填充正确，才能记录为验收通过。

## 验收

1. GUI 可打开、操作和关闭，关闭后游戏鼠标输入恢复。
2. 中心范围圆与菜单半径一致。
3. 圆外、右键松开、菜单打开和失去焦点时不调整视角。
4. 五个部位分别核对真实骨骼与选点；自己和诱饵不参与瞄准。
5. 无遮挡目标只有绿色轮廓，没有红色内部填充。
6. 半身或局部被遮挡时，红色只出现在对应遮挡部分。
7. 完全遮挡时全身红色填充并保留绿色外围。
8. 关闭功能后恢复目标原有高亮状态，不留下方框或持续填充。
